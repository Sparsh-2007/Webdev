# Webdev Learning Journey 🚀

Personal repository documenting my code as I learn HTML, CSS, and modern JavaScript from scratch.

This repo contains my daily practice files, experiments with different HTML5 tags, CSS layouts (Flexbox & Grid), and interactive JavaScript DOM mini-apps.

---

## Folder Structure

### 📁 `HTML/`
* [`index.html`](HTML/index.html) — My first HTML page with bio, favorite movies list, and weekly study routine table.
* [`form.html`](HTML/form.html) — Practice form with text, email, password, date inputs, radio buttons, checkboxes, and select dropdowns.
* [`tags_practice.html`](HTML/tags_practice.html) — Testing miscellaneous tags: `<details>` / `<summary>` spoilers, `<progress>`, `<meter>`, image alt tags, and button alerts.

### 📁 `CSS/`
* [`index.html`](CSS/index.html) & [`style.css`](CSS/style.css) — Styling basics, typography, button states, and visual box model comparisons (margin vs padding).
* [`flexbox.html`](CSS/flexbox.html) & [`flexbox.css`](CSS/flexbox.css) — Responsive horizontal navbar with `space-between` and flex cards with mobile media queries (`@media (max-width: 680px)`).
* [`grid.html`](CSS/grid.html) & [`grid.css`](CSS/grid.css) — Responsive card gallery using CSS Grid `repeat(auto-fit, minmax(280px, 1fr))`, CSS variables, and hover lift effects.

### 📁 `JS/`
* [`index.html`](JS/index.html) & [`basics.js`](JS/basics.js) — Core JavaScript fundamentals: variables, functions, arrow functions, `if/else`, loops, arrays (`.map()`, `.filter()`), and objects.
* [`dom.html`](JS/dom.html), [`dom.css`](JS/dom.css) & [`dom.js`](JS/dom.js) — Interactive DOM playground featuring:
  - Interactive Counter with color-coded feedback (`+`, `-`, `Reset`)
  - Dark mode / Light mode theme switcher
  - Live character count input
  - Dynamic todo / study list with click-to-delete

---

## How to Run

No build tools or installations needed. Simply clone the repository and open any `.html` file directly in your web browser (or use the VS Code *Live Server* extension).
